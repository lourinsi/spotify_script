# 🎵 Spotify Autorun
Automates Spotify actions using Python and Selenium.


# 🚀 Quick Start
1️⃣ Clone the repo 👉 git clone https://github.com/lourinsi/spotify_script.git 👉 cd spotify_script

2️⃣ Create a virtual environment 👉 py -m venv venv 👉 .\venv\Scripts\activate

3️⃣ Install dependencies 👉 pip install -r requirements.txt 💡 If missing: echo selenium > requirements.txt

4️⃣ Download ChromeDriver 👉 Go to: https://developer.chrome.com/docs/chromedriver/downloads 👉 Open Chrome for Testing dashboard 👉 Pick the driver that matches your Chrome version & platform 👉 Extract chromedriver and put it in the project folder or add to PATH

5️⃣ Run the script 👉 py "Spotify Autorun.py"

# 🛠 Requirements
🐍 Python 3.15+

📦 pip

🌐 Selenium

🌍 ChromeDriver (matching your Chrome version)

# ❗ Troubleshooting
🐍 If Python not found → py --version
📦 If Selenium missing → py -m pip install selenium
⚠️ WebDriver errors → Make sure ChromeDriver matches your Chrome version
